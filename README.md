# 🦋 Chatterfly - Веб-мессенджер

Современный мессенджер с текстовыми сообщениями и голосовыми звонками в реальном времени.

## 🌟 Возможности

- ✅ **Реальные текстовые сообщения** между пользователями
- ✅ **Голосовые звонки** через Daily.co
- ✅ **Умная техподдержка** с ИИ-помощником
- ✅ **Профили пользователей** с юзернеймами (@username)
- ✅ **Личные сообщения** и групповые чаты
